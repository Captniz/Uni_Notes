## Funzioni di conversione
| **Categoria**                           | **Funzione / Operatore**               | **Sintassi di Esempio**                                                        | **Descrizione**                                                                                      |
| --------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| **Cast del C++ (Operatori)**            | `static_cast`                          | `static_cast<int>(3.14)`                                                       | Conversione sicura in fase di compilazione (es. da `double` a `int`, tra puntatori correlati).       |
|                                         | `dynamic_cast`                         | `dynamic_cast<Derived*>(basePtr)`                                              | Conversione sicura a runtime per gerarchie polimorfiche (richiede classi con metodi virtuali).       |
|                                         | `const_cast`                           | `const_cast<char*>(constStr)`                                                  | Aggiunge o rimuove il qualificatore `const` o `volatile`.                                            |
|                                         | `reinterpret_cast`                     | `reinterpret_cast<int*>(ptr)`                                                  | Conversione a basso livello del pattern di bit (da usare con cautela).                               |
| **Da Stringa a Numero**                 | `std::stoi`, `std::stol`, `std::stoll` | `std::stoi("42")`                                                              | Converte una stringa (`std::string`) in `int`, `long`, `long long`.                                  |
|                                         | `std::stof`, `std::stod`               | `std::stod("3.14")`                                                            | Converte una stringa in `float` o `double`.                                                          |
|                                         | `std::atoi`, `std::atof`               | `std::atoi("42")`                                                              | Ereditate dal C (header `<cstdlib>`), converte stringhe C-style (`const char*`) in `int` o `double`. |
| **Da Numero a Stringa**                 | `std::to_string`                       | `std::to_string(42)`                                                           | Converte tipi numerici (`int`, `float`, `double`, ecc.) in `std::string`.                            |
| **Arrotondamento (Double/Float a Int)** | `std::round`                           | `std::round(3.7)`                                                              | Arrotonda all'intero più vicino (restituisce `float`/`double`, convertibile a intero).               |
|                                         | `std::floor`                           | `std::floor(3.9)`                                                              | Arrotonda per difetto (all'intero inferiore).                                                        |
|                                         | `std::ceil`                            | `std::ceil(3.1)`                                                               | Arrotonda per eccesso (all'intero superiore).                                                        |
| **Utility Avanzate (C++17+)**           | `std::from_chars`                      | `std::from_chars(ptr, ptr+len, val)`                                           | Conversione ad alte prestazioni da buffer di caratteri a tipi numerici (senza allocazioni).          |
|                                         | `std::to_chars`                        | `std::to_chars(ptr, ptr+len, val)`                                             | Conversione ad alte prestazioni da numero a buffer di caratteri.                                     |
|                                         |                                        | ```int sprintf(char *buffer, const char *format-string, argument-list);<br>``` |                                                                                                      |
